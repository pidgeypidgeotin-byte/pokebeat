# Pokédex de Kanto — assets

PokéBeat incluye las 151 entradas de Kanto como especies jugables en encuentros y captura.

Los sprites locales de **001–101** proceden de [PMDCollab/SpriteCollab](https://github.com/PMDCollab/SpriteCollab), usando `Idle-Anim.png` cuando existe y `Walk-Anim.png` como sustituto para #015. La fuente se carga dentro de `assets/sprites/pmd/` y queda incluida en la APK.

En la consulta del repositorio del 26 de septiembre de 2026, SpriteCollab no tenía carpetas publicadas para **102–151**. Para que las 151 especies sigan siendo jugables desde esta versión, esas 50 fichas usan sprites de fallback de [PokeAPI Sprites](https://github.com/PokeAPI/sprites). Cuando PMDCollab publique esas especies, se pueden sustituir sin cambiar el sistema de rutas, encuentros o captura.

Pokémon y sus nombres son marcas de Nintendo, Creatures y GAME FREAK. PokéBeat es un proyecto no oficial y no comercial.
